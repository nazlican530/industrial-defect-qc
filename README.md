# Industrial Surface Defect Detection System

## Overview

This project presents an AI-powered industrial surface defect detection and quality control system developed using deep learning techniques. The system automatically classifies steel surface defects, generates explainable AI visualizations using Grad-CAM, produces AI-assisted inspection reports, and supports industrial decision-making.

## Features

* Defect classification using EfficientNet-B0 and ResNet50
* Grad-CAM explainability
* AI-assisted reporting module
* Quality control decision support
* FastAPI backend
* MongoDB database integration
* JWT authentication
* Prediction history tracking
* Robustness analysis under noisy conditions

## Dataset

The project uses the NEU-DET dataset containing six defect categories:

* Crazing
* Inclusion
* Patches
* Pitted Surface
* Rolled-In Scale
* Scratches

## Technologies

* Python
* PyTorch
* FastAPI
* MongoDB
* JWT Authentication
* Grad-CAM
* EfficientNet-B0
* ResNet50

## Results

* Accuracy: 92.59%
* Precision: 93.66%
* Recall: 92.59%
* F1-Score: 92.66%
* Inference Time: ~0.14 seconds per image
